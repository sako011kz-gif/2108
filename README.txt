2108 FITWEAR — готовый frontend интернет-магазина

Файлы:
- index.html — структура сайта
- style.css — премиальный адаптивный дизайн
- script.js — каталог, фильтры, поиск, карточка товара, корзина и WhatsApp
- assets/ — локальные изображения, взятые из предоставленного Instagram-скриншота

Перед публикацией:
1. В script.js замените 77000000000 на реальный WhatsApp номер заказчика.
2. Проверьте Instagram @2108_fitwear.
3. В массиве products в script.js замените демонстрационные цены/названия/описания на реальные.
4. Для коммерческой версии лучше заменить crops из скриншота на оригинальные фотографии товаров.
5. Backend не нужен для заказа через WhatsApp/Instagram.
